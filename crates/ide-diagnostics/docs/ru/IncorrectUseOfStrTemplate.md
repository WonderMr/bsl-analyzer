# Неверное использование "СтрШаблон" (IncorrectUseOfStrTemplate)

## Описание диагностики

Диагностика проверяет корректность использования API `СтрШаблон`.

Текущая реализация выявляет несколько типовых ошибок:

- число аргументов не соответствует подстановкам в шаблоне;
- используются недопустимые номера подстановок, например `%0` или `%11`;
- неверно обрабатываются экранированные `%%`;
- шаблон передаётся через переменную, которая в итоге разворачивается в
  некорректную строку;
- из-за неправильно расставленных скобок вокруг `НСтр(...)` вызов получает
  неверное выражение шаблона.

Многострочный литерал шаблона (строки продолжения с `|`) проверяется целиком.
Шаблон, сложенный из строковых литералов (`"Документ №%1" + " от %2"`, в том числе
в скобках и с `НСтр(...)` среди слагаемых), проверяется как одна строка. Слагаемые
`Символы.ПС`, `Символы.ВК`, `Символы.Таб`, `Символы.ВТаб`, `Символы.ПФ` и `Символы.НПП`
читаются как текст без подстановок.

Каждая ветвь `?(Условие, "...", "...")` проверяется как отдельный шаблон. У многоязычной
строки `НСтр("ru = '...'; en = '...'")` отдельно проверяется перевод на каждый язык: перевод,
подстановки которого не совпадают с параметрами, отмечается. Если вторым параметром `НСтр`
передан код языка строкой, проверяется только перевод на этот язык.

Шаблон из локальной переменной проверяется, когда каждое присваивание, которое доходит до
вызова, задаёт шаблон из таких же частей и все они дают один и тот же текст:
`Шаблон = "Документ %1" + " от %2"; Текст = СтрШаблон(Шаблон, Номер)` отмечается.

Если хотя бы одна часть шаблона неизвестна (параметр метода, вызов функции, реквизит
объекта, другое свойство `Символы`), диагностика молчит: подстановки могут прийти из этой
части.

Также важно помнить:

- `СтрШаблон` поддерживает подстановки от `%1` до `%10`;
- если сразу после подстановки должна идти цифра, нужно использовать запись со
  скобками: `"%(1)45"`.

## Примеры

Некорректно: число аргументов не совпадает с подстановками
```bsl
Текст = СтрШаблон("Документ №%1 от %2");
Текст = СтрШаблон("Склад: %1, Ячейка: %2", НаименованиеСклада);
```

Некорректно: ошибка в расстановке скобок с `НСтр`
```bsl
Сообщение = СтрШаблон(НСтр("ru='Версия программы: %1'", НомерВерсии()));
```

Некорректно: одна из ветвей или один из переводов не совпадает с параметрами
```bsl
Текст = СтрШаблон(?(ЕстьДата, "Документ %1 от %2", "Документ %1"), Номер);
Текст = СтрШаблон(НСтр("ru = 'Документ %1'; en = 'Document'"), Номер);
```

Корректно:
```bsl
Сообщение = СтрШаблон(НСтр("ru='Версия программы: %1'"), НомерВерсии());
Текст = СтрШаблон("%(1)07", Код);
Текст = СтрШаблон("Вид: %1" + Символы.ПС + "Код: %2", Вид, Код);
Текст = СтрШаблон(?(ЕстьДата, "Документ %1 от %2", "Документ %1 (%2)"), Номер, Дата);
```
